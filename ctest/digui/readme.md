相全，递归要“能跑完不炸”，核心就两个限制条件：

终止条件（base case）必须存在且可达
也就是总有一次会走到“不再递归”的分支，否则就无限递归直到栈溢出。

每次递归必须让问题规模变小（趋近终止条件）
比如 a 变成 a/10、n 变成 n-1。如果规模不减、甚至可能来回跳，就会卡死或爆栈。

你那个例子里：

终止条件：a < 10

规模变小：a = a/10（一直变小，必然到 1 位数）




# 函数栈帧：创建与销毁（配递归例子）

## 1. 栈 / 栈帧是什么（直觉版）

* **栈（stack）**：一摞盘子，后来的放最上面（LIFO：后进先出）。
* **栈帧（stack frame）**：一次函数调用占用的“那一层盘子”。
* 每调用一次函数，就会**新建一个栈帧**；函数返回时，这个栈帧会**被销毁**（弹出）。

---

## 2. 栈帧在做什么（创建/销毁流程）

### 创建（进入函数）

一次典型的函数调用（概念层面）会发生：

1. **call**：把“返回地址”压到栈上（回到调用点的下一条指令）。
2. 进入被调函数后，为它**建立栈帧**：

   * 保存必要的寄存器/上一层的帧信息（取决于平台/编译器）
   * 给局部变量、临时量等预留空间

> 栈帧里常见内容：返回地址、保存的寄存器/帧指针、局部变量、可能的栈上传参区等。

### 销毁（函数返回）

1. 恢复栈指针/寄存器（把“盘子”腾出来）
2. **ret**：弹出返回地址，跳回调用点继续执行
   => 这层栈帧被销毁，栈顶回到上一层函数。

---

## 3. 必记结论（防踩坑）

* **函数返回后，它的栈帧就没了**，里面的局部变量空间会被复用。
* 所以 **不要返回局部变量地址**：

```c
int* f() {
    int x = 3;
    return &x;   // 错：返回后 x 所在栈帧已销毁，&x 变成悬空指针
}
```

---

## 4. 例子：递归打印数字（栈帧如何“叠盘子/收盘子”）

代码：

```c
#include <stdio.h>

void print(unsigned int a)
{
    if (a >= 10)
    {
        print(a / 10);
    }
    printf("%u\n", a % 10);
}

int main()
{
    print(1234);
    return 0;
}
```

### 4.1 递归“下潜”阶段：只建栈帧，不打印

`print(1234)` 会先递归调用：

* `print(1234)` → `print(123)` → `print(12)` → `print(1)`

当到达最深处 `print(1)` 时，栈（从底到顶）大概是：

```
main()
print(a=1234)
print(a=123)
print(a=12)
print(a=1)   ← 栈顶（最新调用）
```

每一层 `print(a=...)` 都是一个独立栈帧（各自保存自己的参数 a、返回地址等）。

### 4.2 “上浮”阶段：边返回边打印，栈帧一层层销毁

关键：`printf` 在递归调用 **之后**：

```c
if (a >= 10) print(a/10);
printf("%u\n", a%10);
```

所以顺序是：

1. 在 `print(a=1)`：不再递归，执行 `printf(1%10)` → 打印 `1`，然后返回（这一层栈帧销毁）
2. 回到 `print(a=12)`：继续执行 `printf(12%10)` → 打印 `2`，然后返回（栈帧销毁）
3. 回到 `print(a=123)`：打印 `3`，返回
4. 回到 `print(a=1234)`：打印 `4`，返回到 `main`

最终输出：

```
1
2
3
4
```

### 4.3 一句话总结递归与栈帧

* **下潜**：不停调用更小问题 → 栈帧不断叠加
* **上浮**：最深层先返回 → 栈帧不断弹出，同时执行“递归调用之后”的代码（这里就是 printf）

---

## 5. 你可以用来对照的“栈帧视角”

* “每一层 print(a=xxx) 都有自己独立的 a”
* “返回地址保证每层 return 后能回到那层的 printf 继续执行”
* “栈帧销毁 = 那层的局部数据不再可靠（会被后续调用覆盖）”
